Resource Manager ↗

C++20

Central hardware broker. Manages task scheduling, priority preemption, and IQ fan-out to multiple consumers — all without any consumer knowing about the others.

Rank preemption

3-tier priority: Acquisition (1) < Classification (2) < Direction Finding (3). Higher-rank tasks preempt lower-rank and release hardware on completion.

Shared-LO fan-out

Two tasks at the same frequency share one hardware channel via sub-band decomposition. Zero re-tuning overhead.

Independent-LO

On multi-channel SDRs, tasks at different frequencies run truly simultaneously on separate RF chains.

Combined-window

A new task within the device's instantaneous BW triggers a retune to a new centre covering both — neither stream drops.

Unit tests200+ — scheduling, preemption, port allocation, concurrent tasks, coherent multi-board
Hardware testsValidated against live SDR hardware via SoapySDR fake driver

AcquisitionApp ↗

C++2064 tests ✓

Continuous spectrum scanner. Submits frequency-sweep tasks, receives raw IQ over UDP, and runs a four-stage detection pipeline. All detections persist to PostgreSQL and stream to AMQP.

📊
Welch averaging

50%-overlapping Blackman-Harris windowed FFT frames. Reduces noise variance ~18 dB vs single-shot FFT.

→
🎯
CA-CFAR

O(N) prefix-sum, 8 guard + 32 reference cells per side. Threshold adapts to local noise density.

→
🔁
Persistence filter

Signal must appear in ≥2 consecutive sweeps. Strong signals (PAPR ≥15 dB) bypass and emit immediately.

→
📍
Sub-bin interpolation

3-point parabolic fit on peak bin. ~1–2 kHz accuracy regardless of FFT resolution.

Sweep rate~7.6 s / 920 MHz sweep at 20 MSPS (no analysis window)
Minimum detectable−98 dBm with PAPR ≥ 3 dB reliably detected in live tests
Frequency accuracy±1–2 kHz with sub-bin interpolation at typical sample rates
False alarm controlCFAR threshold_db + 2-sweep persistence confirmation

AnalysisApp — Signal Classification ↗

C++2033 tests ✓

Automatic modulation recognition (AMR) via a two-path ONNX pipeline. Classifies every detected signal without manual tuning.

Fast path — ~5 ms

36-class ResNet runs on the 1024-sample IQ snapshot already embedded in every RF_DETECTION. No SDR re-acquisition. Fires when confidence ≥ 0.75.

Slow path — ~80 ms

Fetches 65k fresh samples via NARROWBAND task. Computes 4th-order cumulants, OFDM CP ratio, FM deviation, chirp rate. Feeds rule engine + ONNX in parallel.

ML accuracy — 28-class baseline model (val_acc = 0.743)

DfApp — Direction Finding ↗

C++20CI ✓

Bearing estimation via the MUSIC algorithm. Requires multiple time-coherent receivers sharing a common LO reference (GPS-disciplined or hardwired). Works with any multi-element antenna array.

PMUSIC(θ) = 1 / ‖ ENH a(θ) ‖² — swept at 0.5° resolution

Measured bearing accuracy

5-element UCA, SNR 25 dB< 2° error at all tested azimuths (0° / 90° / 135° / 180° / 270°)
5-element UCA, SNR 10 dB< 3° — still convergent at moderate noise
2-element baseline, SNR 25 dB< 5° — minimum viable config, reduced accuracy
UHF 433 MHz< 2° — wavelength change handled correctly (steering vector recomputed)
Confidence outputConfidence score derived from MUSIC peak sharpness — reported alongside azimuth

SpeechApp — Voice Transcription ↗

C++20 core

Passively subscribes to rf.demod audio. Two-stage pipeline: energy VAD gates Whisper, then whisper.cpp (C++ GGML — no Python runtime) transcribes detected speech. Every detection is stored in SQLite and a rolling daily text log.

EnergyVad (<1 ms)

RMS energy gate in dBFS. Rejects silence, noise bursts, DTMF, tones. Only audio with speech-band energy passes to inference.

whisper.cpp

GGML-quantised Whisper. CPU or CUDA. Auto language detection. Segment output to word boundaries. Runs on the same machine as the rest of the stack.

Measured STT performance

VAD at SNR 5 dBp = 1.000 — voice detected through 50 Hz hum, 2 multipath dropouts
Whisper base at SNR 20 dBWord-perfect: "SDR radio check. Alpha Bravo Charlie. Signal is weak but readable. How copy? Over."
Whisper base at SNR 5 dB"SBR video check, Alph Bravo Charlie, signal is weak but readable, how copy, over." — key info preserved, minor acronym / dropout errors
Whisper base at SNR 0 dBHeavy paraphrasing — meaning partially preserved, details unreliable
Breakdown threshold−6 dB SNR and below: hallucination (plausible-sounding but unrelated text)

SdrSdk ↗

C++20

C++ library for writing SDR applications without touching AMQP or raw socket internals. Wraps task submission, IQ streaming, and spectrum analysis into a clean API with physical-unit safety via Au units.

#include <sdrsdk/sdrsdk.hpp>
#include <au/units/hertz.hh>

sdr::SdrClient client("amqp://localhost:5672");
client.connect();

// Capture 3 s at 462.5 MHz, 48 kHz SR
auto resp = client.narrowband(au::hertz(462.5e6), au::hertz(12.5e3),
                               au::hertz(48e3), au::seconds(3.0));

sdr::IqStream stream(resp.streams[0].udp_port);
auto iq = stream.collect_complex_for(au::seconds(3.0));

// Analyse
sdr::Spectrum spec(4096);
auto sigs = spec.analyse(iq, au::hertz(462.5e6), au::hertz(48e3));
for (auto& s : sigs)
    std::cout << s.freq.in(au::mega(au::hertz)) << " MHz\n";
