ADS-B Extended Squitter (DF 17) — 112 bits
1090 MHz1 Mbps PPM112-bit frameCRC-24AdsbDemod

Each aircraft transmits an unsolicited 112-bit squitter every ~0.5 s. The 56-bit message payload encodes position, velocity, identity, or status depending on the Type Code (TC).

AIS VDM — ITU-R M.1371 Message Type 1 (Position Report Class A)
161.975 / 162.025 MHz9600 baud GMSK168-bit payloadHDLC framingAisDemod

AIS transmits over NMEA 0183 encapsulation. The VDM sentence carries ASCII-armored binary payload. Message Type 1/2/3 are Class A position reports sent every 2–10 seconds while underway.

P25 TSBK — Trunking Signaling Block (Group Voice Grant)
138–900 MHz9600 baud C4FM / QPSK96-bit TSBKCRC-16P25ControlDecoder

The P25 control channel broadcasts Trunking Signaling Blocks at 3840 TSBKs/min. Open RF Stack parses every TSBK to extract voice grants and follow traffic in real time.

EAS SAME Header — FCC Part 11 Emergency Alert System
162.4–162.55 MHz520.83 baud FSKASCII textNOAA WX channelsEasSameDemod

EAS alerts begin with a SAME header transmitted three times in FSK on NOAA Weather Radio channels. The header encodes originator, event code, area, expiry, time, and call sign — all as ASCII.

DSC Distress Call — ITU-R M.493 Digital Selective Calling
156.525 MHz (Ch 70)1200 baud FSK10-bit symbols (error detection)GMDSSDscDemod

DSC is the digital distress calling protocol used by GMDSS-equipped vessels. A distress call is the highest-priority message, triggering an audible alarm at all receiving coast stations and vessels.
