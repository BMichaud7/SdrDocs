Reading Spectrograms

Constant block = continuous carrier

FM, PSK, QAM occupy a fixed bandwidth continuously. Width = signal bandwidth, brightness = power.

Discrete lines = FSK tones

2-FSK has 2 horizontal lines, 4-FSK has 4. Each line is one frequency the transmitter switches between.

Diagonal stripe = chirp (LFM/CSS)

LFM sweeps frequency vs time → distinctive diagonal. Slope = chirp rate (Hz/s). LoRa uses stacked chirps.

Flat rectangle = PSK/QAM

Higher-order constellations (QAM256 vs BPSK) have nearly identical spectral shape — this is why ML is needed to distinguish them.

Burst pattern = ADS-B/OOK

ADS-B: short wideband pulses (120 μs). OOK: carrier switched on and off. Both show as intermittent flashes.

Subcarrier grid = OFDM

OFDM has a flat rectangular envelope with faint vertical striping from individual subcarriers. Very distinctive flat top.
